# Strategic rethink council
**Defender:** strongest case for current strategy.
**Adversarial Falsifier:** attempts to disprove key assumptions and identify failure modes.
**First-Principles Architect:** proposes simpler alternative implementations.
**Synthesizer:** compares alternatives, costs, security, expected value, and recommends retain/revise/research/escalate.

Trigger only on meaningful evidence or explicit human request. Council recommendations do not authorize changes to mission, security invariants, or external systems.
