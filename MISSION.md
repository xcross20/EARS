# Mission
Build a credible, executable enterprise AI reference system that demonstrates useful financial-operations automation with authorization-safe retrieval, human control of consequential actions, and independently verifiable evidence.

## Non-negotiable invariants
- Synthetic data only; never execute payments.
- Server-side tenant and role authorization precedes data retrieval and tool execution.
- LLM recommendations are not authorization decisions.
- No self-approval; manager decision is recorded.
- Every material action has an attributable audit event.
- No unverified claims of production readiness.

## Success
A browser user can complete J001 as analyst, manager, and auditor; negative authorization tests pass; the system starts from documented local commands; independent review accepts evidence.
